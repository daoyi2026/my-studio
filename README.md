# My Studio

Daoyi's interactive 3D studio, built with Three.js and published as a static
GitHub Pages site.

## Local preview

```bash
npm run dev
```

Open `http://127.0.0.1:4174/`.

## Verification

```bash
npm run check
```

The production check verifies the release model, accepted R7 lighting atlas,
required media, and deployment entry points.

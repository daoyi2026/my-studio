# Security Policy

Kinetic Life OS is a static, local-first application. It does not provide authentication, cloud storage, or cross-device synchronization.

## Supported version

Only the latest version deployed from the `main` branch is supported.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the repository owner instead of opening a public issue with exploit details.

## Data safety

Application data is stored in the visitor's browser. Browser-local storage is not encrypted and should not be used for passwords, payment details, identity documents, or other highly sensitive information. Users should export JSON backups regularly.
